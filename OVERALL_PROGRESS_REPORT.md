**Overall Progress of the System**

Our team is making steady progress on the project, and we are currently on schedule according to our project timeline. Our main goal for this period was to build the fundamental parts of the system, and we have successfully achieved that.

What We Have Accomplished:

- User Registration and Login System: We have built a secure system that allows a customer to sign up for a new account, log in with their details, and log out. The system also supports password recovery in case a user forgets their password. This is a crucial first step for personalizing the user experience.

- Main Dashboard: After an administrator logs in, they land on a functional dashboard. We designed it to be the central hub where the admin can see important information such as new bookings, pending payments, customer concerns, and unread messages, and easily access the other features of the system.

- Event Booking System: Customers can now book an event by choosing a date, time, event type, location, and package. The admin can confirm, decline, or complete bookings, and customers can also send edit or cancellation requests with their reasons. The system also blocks dates that the admin has marked as unavailable so customers can no longer book them.

- Payment System: We have implemented a payment process where customers can upload their proof of payment, such as a GCash screenshot, and the admin can verify and approve it. The system tracks whether a booking is partially paid or fully paid based on the downpayment percentage set by the admin.

- Package and Gallery Viewing Page: Users can now browse the available packages with their images, inclusions, and prices displayed clearly, and they can also view a gallery of the past works of the business organized by category.

- Custom Design Canvas: We have built a design editor where customers can create their own balloon and event styling designs. They can add text, shapes, and decorations, move them around, and save their designs, which they can then attach to their booking.

- AI Chat and Messaging Support: We have integrated an AI chatbot that can answer customer questions automatically, and if the concern is too complicated, the conversation can be transferred to a live admin. The chat also supports sending images, replies, and reactions, and it automatically filters offensive messages.

- Reviews, Ratings, and Concern Tickets: Customers can leave a review with a rating and photos after their event, and the admin can post an official reply to each review. Customers can also report concerns or problems through a ticket system that the admin can track until it is resolved.

- Initial Database Setup: We have successfully set up the project's database. This is like the brain of our system, where all important information, such as user accounts, bookings, payments, designs, packages, and reviews, is stored safely.

- Enhancing UI/UX Design: As per the advice of the panelist, the system design was enhanced for better user experience, such as making a better choice of color coding, adding a light and dark mode toggle, and making the pages responsive on mobile phones, tablets, and computers.

- Reports and Analytics: We have added an analytics page for the admin that summarizes the sales, bookings, and customer feedback of the business, which can also be exported as an Excel file or a PDF report.

Challenges Faced: This past month, we faced a small challenge in balancing our time between building new features and fixing the design of the system, since some pages needed to be adjusted to work properly on smaller screens. We solved this by testing each page carefully and fixing the layout one by one, as shown in our latest updates on the booking page, designs page, and login and registration pages. We also made sure to keep a backup of our work in case a problem arises again.

Our Goals for the Next Period:

- Complete the Card Payment Option: We will finalize the remaining part of the payment system so customers can also pay using a card, not just GCash.

- Begin Initial Bug Testing: We will start carefully testing all the finished parts of the system to find and fix any errors.

- Prepare the System for Deployment: We will polish the settings needed to run the system online, such as the file storage and email notifications, so the business owner can start using the real system.

- Final Responsive and Design Check: We will do a final review of all the pages to make sure everything looks clean and works well on any device before the final presentation.
