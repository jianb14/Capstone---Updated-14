The polygon determines whether the venue receives the Cavite base fee. Distance
uses the existing straight-line Haversine tariff, not road distance. Outside
Cavite, the existing included radius and per-kilometer tariff apply, with at
least one billable kilometer. The shop address and exact pin are maintained in
Site Settings. Without a saved pin, the configured business address is geocoded
and cached. A missing origin is reported rather
than presenting the base fee as a completed distance quote.
