About these figures

Success rate counts succeeded requests out of finished requests. Queued and running requests are excluded. Processing time runs from worker start to finish, including failed attempts; queue time is excluded. P95 is the time within which 95% of the sampled finished requests completed.

Reply repairs counts requests where automatic reply correction was attempted. A clarification fallback means the reply check still did not pass. These are technical checks, not customer satisfaction ratings. Processing, reply checks and text usage use the latest {{ sample_limit }} requests at most; counts and activity cover the whole selected period.

AI Health helps you investigate errors and delays. It reads saved request records without sending paid test requests. It does not measure image quality or guarantee that the provider is currently available.
