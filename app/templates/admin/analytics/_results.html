How to read this report

Booking figures follow the selected booking date basis and event type. Statuses and payments reflect their latest recorded state.

Completed booking value is the final price of completed bookings. Verified collections includes only verified payments credited to the selected bookings, regardless of payment date; it excludes pending, rejected and unapplied change payments. It is not a net revenue or refund report.

Payments received uses the date range independently of booking dates, with the same event type filter. Receipt timestamps take priority; verification timestamps are used only where receipt timestamps are missing. Undated verified payments are flagged and excluded from dated collections.

Rates use all selected bookings as the denominator. Setup demand counts the main setup once per booking; optional add-ons are excluded. Event and setup charts group selections beyond the top six into one total.
