# SVG / Asset Style — Lineal Color Icon

ALL generated SVG assets (balloons, furniture, decorations, frames, party items, themes,
text signs) must strictly follow `design-guide.md`:

1. Bold black outline: `stroke="#222"` with `stroke-width="1"`, round caps/joins
   (`stroke-linecap="round" stroke-linejoin="round"`).
2. ONE flat solid color fill per shape — NO gradients, NO metallic sheen, NO glassmorphism.
3. NO highlights (white reflection dots), NO glow, NO drop shadows, no blur filters.
4. Clean, minimal, Flaticon "Lineal Color" pack look; isolated object on a transparent
   background with no extra accessories.
5. Balloons: pure circle/ellipse, heart, star, number, or letter shape — NO string, NO
   stick, NO knot, NO tie.

Use the exact palette from `design-guide.md`:
Red `#e63946`, Blue `#4895ef`, Yellow `#fee440`, Green `#06d6a0`, Pink `#ffb3c6`,
Purple `#9d4edd`, Orange `#f77f00`, Gold `#ffb703`, Silver `#ced4da`, White `#f8f9fa`,
Black `#212529`, Brown `#8b5a2b`, Cream `#faf0e6`, Sage `#a7c4a0`.
